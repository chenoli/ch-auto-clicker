# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

Windows executables and installers of CH Auto Clicker are built by GitHub Actions from tagged commits of this repository and are signed only after the build passes every CI check. Nothing built on a personal computer is signed.

## Team roles

- Committers and reviewers: Carlos Henrique de Oliveira ([@chenoli](https://github.com/chenoli))
- Approvers: Carlos Henrique de Oliveira ([@chenoli](https://github.com/chenoli))

## Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it, with one exception: to keep itself up to date, the app downloads a small version file from [GitHub Releases](https://github.com/chenoli/ch-auto-clicker/releases) about 30 seconds after it starts and once a day. This request sends no personal data or usage information; GitHub receives it like any other download.

Full privacy policy: <https://chenoli.com.br/clicker/privacy>
